## Controllers (same sample time 0.1 min, same bound 0.0018 <= u <= 0.0024)
1. PID-orig: upstream control.m law and gains, incremental form, saturation as upstream.
2. PI-tuned: IMC-style PI from the FOPDT fit of the Python STEP (tau = 0.0505 min, dead time
   0.2035 min) and the nominal steady-state gain K = dH2/du from the map at u = 0.0021; closed-loop
   time constant = dead time; Kc = tau / (K (tc + theta)), Ti = min(tau, 4 (tc + theta));
   velocity form with the same saturation (no extra windup since velocity form).
3. MPC: prediction model = steady-state map gain at NOMINAL health with a first-order lag (tau,
   theta above), offset-free output disturbance d = y_meas - y_model filtered (first order, 0.5 min);
   horizon 1.0 min (10 steps), 3 blocked moves; cost sum (y - sp)^2 / sd_H2^2 + 10 * sum (du / 1e-4)^2;
   bounded solve (scipy). Steady-state target u_t solves model(u_t) + d = sp; if u_t > 0.0024 the
   controller DECLARES INFEASIBLE (logged with time) and holds u at 0.0024 instead of chasing.
4. MPC+health: same as 3, but the prediction model is the 2-D map at the current MHE estimate
   (M6 estimator, S4 measurements, updated every 1 min); infeasibility is declared from the
   health-aware steady-state target.
