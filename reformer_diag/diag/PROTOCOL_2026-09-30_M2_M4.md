## 1. Model basis: quasi-steady map

Deterioration in the benchmark is slow (authors' rates 0.01 and 0.006 per min, i.e. time
constants 100 and 167 min) against the reactor response (under 1 min). Results therefore use
steady states on a grid, interpolated:

- Activity multipliers: a_c scales all four kinf; a_m scales pe0 (`FaultParameters`, a subclass;
  model.py is not edited).
- Grid per mode: a_c in {1, .95, .9, .8, .7, .6, .5, .4} with a_m = 1; a_m in {.95, .9, .8, .7, .6,
  .5, .4} with a_c = 1; ethanol u in {.0018, .0019, .0020, .0021, .0022, .0023, .0024} mol/min;
  water fixed at the mode's u_ss(2). Pressure and inlet temperature per mode.
- Steady state: BDF from the mode's ICFull state, rtol 1e-6, atol 1e-8, integrated in 1-min
  chunks until |dH2| over the last 0.5 min < 1e-6 relative, max 12 min; non-converged points are
  kept and flagged, never dropped silently.
- Observables from `evaluate`: permeate H2 (mol/min), outlet temperature (K), waste volumetric
  flow (m3/min), waste mole fractions of H2, CH4, CO, CO2 (micro-GC set).
- Interpolation: cubic spline in severity, cubic in u (scipy RectBivariateSpline on each line).

Validation gates (computed first; failure stops M3/M4 for that mode and is reported):
- V1 quasi-steady: full dynamic run of the authors' disturbance 3 (catalyst, exp(-0.01 t)) and
  4 (membrane, exp(-0.006 t)), Mode 1, open loop, u = 0.0021, 20 min, 0.1-min outputs; compared
  with the map prediction at a(t). Gate: max |dH2| <= 0.5% of nominal H2 for t >= 1 min.
- V2 interpolation: direct steady states at (a_c = .85, u = .00215) and (a_m = .85, u = .00215),
  Mode 1, vs map prediction. Gate: |dH2| <= 0.2% of nominal; other observables reported.

## 2. Measurement layer (M2)

Declared scenario values (not manufacturer specifications, not plant values):

| signal | noise sd | unknown constant bias bound | sampling | delay |
|---|---|---|---|---|
| permeate H2 flow | 0.5% of mode nominal H2 | 0.5% of nominal | 0.1 min | 0 |
| outlet temperature | 0.5 K | 1.0 K | 0.1 min | 0 |
| waste volumetric flow | 1% of reading | 2% of reading | 0.1 min | 0 |
| waste mole fractions (H2, CH4, CO, CO2) | 1% relative, floor 0.001 | 2% relative | 3 min | 3 min |

Ethanol command history is known exactly (actuator). Sensitivity: whole map repeated with all
noise and bias values x0.5 and x2.

Measurement sets: S1 {H2}; S2 {H2, T_out}; S3 {H2, T_out, waste flow}; S4 {S3 + mole fractions}.
Decision window: 10 min of quasi-steady data (n = 100 fast samples; GC n = floor((10-3)/3)+1 = 3).

Feed-move experiment E (bounded): ethanol command +0.0003 mol/min (Mode 1: .0021 -> .0024;
Mode 2: .0018 -> .0021), 1 min settling discarded, 5 min held (n = 50 fast samples, GC n = 1),
then return. Adds, for the same measurement set, the level-2 minus level-1 differences (bias
cancels in differences). Cost reported: extra ethanol 0.0003 x 6 = 0.0018 mol per move.

## 3. Hypotheses (single fault, one scalar severity each)

- C catalyst: a_c = theta in [.4, 1].
- M membrane: a_m = theta in [.4, 1].
- F feed shortfall: delivered ethanol = theta x command, theta such that delivered >= .0018.
- S H2 sensor drift: measured H2 = true + b, b in [-20% nominal, 0]; other signals nominal.

True scenarios: each hypothesis at severities giving an H2 drop of 1, 2, 5, 10, 20% of the mode's
nominal H2 at the mode's u_ss ethanol (open loop, constant command). Scenarios a hypothesis
cannot reach inside its range are marked UNREACHABLE.

## 4. Distinguishability statistic

For measured feature i with n_i samples, sd s_i and bias bound B_i, the residual between the true
scenario and an alternative prediction is r_i; effective r_i' = max(|r_i| - B_i, 0).
Lambda = sum_i n_i (r_i'/s_i)^2 (+ for E: sum over difference features d_j of (r_dj / s_dj)^2 with
s_dj = s_j sqrt(1/n_1 + 1/n_2), no bias term). For each alternative hypothesis, theta' minimises
Lambda over its range (bounded scalar search, 200-point grid then refine). The alternative is
REJECTED if min Lambda > Lambda*, Lambda* = chi-square 0.99 quantile with (k - 1) dof, k = number of
features, minimum 1 dof. Structural check first: rank of the finite-difference sensitivity
matrix (features x {theta_C, theta_M, theta_F, b}) at nominal, per set, with and without E; stated
as the structural identifiability evidence (local, numerical).

## 5. Actions and regions

Action for a hypothesised state: for C, M, F compute the command u_req restoring true H2 to the
mode set-point `ss`; u_req <= .0024 -> COMPENSATE; else SERVICE_CATALYST / SERVICE_MEMBRANE /
REPAIR_FEED respectively (demand infeasible within the benchmark's input bound). For S:
RECALIBRATE (do not change feed).

Region per (mode, set, true hypothesis, drop level):
- DISTINGUISHABLE: every alternative rejected.
- SAME_ACTION: some alternative not rejected, and all non-rejected alternatives share the true action.
- DIFFERENT_ACTION: some non-rejected alternative has a different action.

## 6. Cost of a wrong action (operator units) and value of information

- truth C/M/F, action RECALIBRATE: H2 shortfall rate = ss - H2_true(command) (mol/min).
- truth S, action COMPENSATE: excess ethanol = u_req(alternative) - command (mol/min).
- truth needing service, other service or COMPENSATE chosen: shortfall = ss - H2_true(.0024) (mol/min).
Expected cost with a set: average over non-rejected hypotheses (true included) of cost(true,
action(alt)), equal odds (declared). VOI of a set = mean over scenarios of [cost with S1 - cost
with the set], reported separately for H2 shortfall (mol/min) and ethanol excess (mol/min), per
mode. One figure: VOI per measurement set and for E.

## 7. M3 worked case (fixed now)

Mode 1, command .0021, catalyst loss giving a 5% H2 drop (true) vs the membrane loss giving the
same H2 reading. Report: both severities, every observable under both, residual per sensor vs
noise floor (in sd units, before and after bias), the E response under both, Lambda for each.
Stopping rule: after E, if exactly one of C, M has Lambda <= Lambda*, declare it; if both <=
Lambda*, extend E to 10 min once; if still both, declare INCONCLUSIVE; if neither, declare
"deteriorated, cause not in C/M". Also the time view: the authors' catalyst schedule
exp(-0.01 t) over 0-30 min and the membrane schedule that reproduces its H2 exactly (map inversion).

## 8. Stop rules

A failed validation gate stops that mode's M3/M4 and is reported. Failed or surprising results
are kept. No parameter, noise level, threshold or rule above is changed after seeing results;
any change is a dated amendment with the old result kept.
