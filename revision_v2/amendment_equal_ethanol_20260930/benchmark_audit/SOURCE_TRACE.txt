1. IAE definition: CONFIRMED mathematical distinction, not a proved author bug.
Primary source: major_revision_v2/sources/benchmark.pdf, printed page 8 Eq.(13),
visually inspected at benchmark_page8_internal.png. Paper title: "A benchmark
simulator for advanced control of ethanol steam reforming".
Literal formula applied to the saved rows: sum(abs((e[k]+e[k-1])/2)*dt[k]).
Conventional trapezoidal IAE: sum((abs(e[k])+abs(e[k-1]))/2*dt[k]).
The latter exceeds the former on sign-crossing intervals. Both are numerical
approximations. Do not call either an exact integral of interpolated |e|.
Native baseline trace columns: displayed minutes, hydrogen mol/min, ethanol
mol/min, setpoint mol/min. The checker recomputed all three closed-loop cases,
with no row deletion or time shift, and matched saved MATLAB state arrays.
Full three-case results are integration_rule[] in findings_evidence.json.
Original paper-target failures are not relaxed or replaced by a new formula.
This lane did not infer that integration-rule dependence explains the entire
published discrepancy.

3. PID state carryover: CONFIRMED source mechanism, effect magnitude NOT REPLAYED.
Primary source: baseline pinned SSMR_simulator/control.m, persistent declarations
lines 3-4; emptiness initialization lines 15-18; state updates lines 19-23.
SSMR_simulation.m line 3 starts with clear; close all; clc; and contains no
clear control. Current control.m bytes match the earlier checked pinned Git
blob. The scalar check demonstrates that retained integral state changes the
output even if current error is zero. Its numbers are synthetic fixtures,
not native-plant measurements and must not appear as benchmark effect sizes.
MathWorks documentation consulted read-only:
https://www.mathworks.com/help/matlab/ref/persistent.html
https://www.mathworks.com/help/matlab/ref/clear.html
The documented remedy for this standalone function is clearing the named
function before independent cases. Do not generalize this to resetting a
controller on every sample, or to clearing persistent state in nested functions.
The original +20.12% claim came from a transcribed MATLAB screenshot. It is
not promoted to a raw-CSV remeasurement by this lane and is omitted from the
half-page note wording.
